Analyze the Data

Project Overview

DataLens is a responsive Data Analytics Dashboard designed to analyze datasets and visualize important insights.

Features

- CSV file upload
- Data search and filtering
- Interactive bar charts
- Category breakdown pie chart
- Total and average calculations
- SQLite database integration
- Export filtered data to CSV
- Responsive user interface

Technologies Used

- React.js
- JavaScript
- CSS
- Node.js
- Express.js
- SQLite

Project Goal

To analyze data, understand trends, and present information using charts and summary statistics.
